# ⚡ Interactive Logic Gates PowerPoint Presentation - Demo Teaching

An interactive web-based PowerPoint presentation created for **Troy Lits D. Dancel (BSIT-31A)** for demo teaching on **Architecture / Digital Logic Gates**.

Based on the detailed lesson plan: `LESSON-PLAN-NI-YORT.docx`.

---

## 🚀 Features

- **Cyber Circuit Tech Theme**: Dark glassmorphic slide deck with dynamic glowing circuit canvas background, animated signal paths, and crisp typography (**Outfit**, **Inter**, **Fira Code**).
- **18 Complete Interactive Slides**:
  1. Title Slide & Presenter Card
  2. Learning Objectives & Performance Standards
  3. **T.R.O.Y.** Classroom Rules (Try your best, Raise others up, Open your mind, Your actions matter)
  4. Computer Ethics Review
  5. **"Light Up the Stage" Motivation Game** (Interactive switch mystery boxes unlocking the word **LOGIC**)
  6. Transistor & Logic Gates Concept
  7-13. **Live Interactive Simulators & Truth Tables** for all 7 Logic Gates:
     - **AND Gate** (Flat left, curved right "D" shape)
     - **OR Gate** (Curved back, pointed tip)
     - **NOT Gate** (Triangle with bubble tip)
     - **NAND Gate** (AND gate + bubble tip)
     - **NOR Gate** (OR gate + bubble tip)
     - **EXOR Gate** (Exclusive OR)
     - **EXNOR Gate** (Exclusive NOR)
  14. Generalization & Class Recapping (Easiest vs Hardest gate)
  15. 1-Minute Reflection Prompt
  16. **"Pick the Gate Symbol!" Activity** with 10-second countdown timers
  17. **15-Item Interactive Evaluation Quiz & Truth Table completion**
  18. Next Meeting Assignment & Conclusion
- **Teacher Spoken Script Drawer (`Press N`)**: Displays the exact teacher script and expected student answers at every slide for seamless demo teaching.
- **Slide Overview Modal (`Press O`)**: Grid thumbnail layout to instantly jump to any slide.
- **Presenter Timer**: Real-time timer badge to monitor lesson pacing.
- **Web Audio FX**: Built-in audio tone feedback for switches, buttons, and games without external assets.

---

## ⌨️ Controls & Keyboard Shortcuts

- `Right Arrow` / `Space` / `PageDown`: Next Slide
- `Left Arrow` / `PageUp`: Previous Slide
- `N`: Toggle Spoken Teacher Dialogue Script Drawer
- `O`: Toggle Slide Overview Grid View
- `F`: Toggle Fullscreen Mode

---

## 🛠️ How to Run Locally

Simply open `index.html` in any web browser! No installation or local server required.
